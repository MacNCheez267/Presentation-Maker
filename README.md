# Presentation-Maker

A platform-neutral skill for creating, templating, editing, and reviewing presentations. 

## Usage

Give a topic, brief, source material, existing deck, or design request.

Specify platform, audience, purpose, length, style, and source requirements when they matter.

## Workflow

1. User requests.
> Example: Create a concise introductory presentation comparing prokaryotic and eukaryotic cells for a general audience.

2. Assess and identify the request's mode and scope.

2. If the request lacks clarity, then it will ask concise questions to clarify missing material gaps. Establish audience, purpose, outcome, and delivery needs.

3. If the initial request did not specify: story, style, colors, typography, imagery, charts, and effects. Select from available references from the framework that fit the request and its limits best. 

4. Gather content, verify material claims, and plan the story. General decks use presentation structures.

6. Perform a pre-delivery check. Inspect the preview; the following content should be checked: accuracy, story, readability, accessibility, and visual consistency.

7. Report the confirmed file or link, summary, design choices, checks, and any limitations. Follow tool-required approvals before committing; don’t publish or share unless requested.
