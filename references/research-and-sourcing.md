# Research and Sourcing

Use this reference when a presentation needs factual content beyond the user's supplied material or when existing claims need verification.

## Choose and verify sources

- Prefer sources the user supplied or explicitly approved for the task. Preserve their meaning; distinguish direct quotations from paraphrases and summaries.
- For new factual claims, prefer current primary sources from the responsible organization, dataset, study, or official documentation. Use strong secondary sources when a primary source is unavailable or does not explain the context.
- Verify time-sensitive claims with current sources. Record the publication date and the date the claim describes when they differ; keep geography, population, units, and timeframe attached to the claim.
- Match each claim to what its source actually supports. Do not turn association into causation, a forecast into a fact, or an estimate into a guaranteed outcome.
- Do not invent or silently calculate figures. If a calculation is useful, retain the inputs, method, units, and period so the result can be checked.
- If sources conflict, check whether they use different methods, dates, definitions, or populations. Explain material differences or uncertainty; ask the user only when the choice changes the presentation's conclusion.

## Cite clearly

Cite material external facts by default. Put a short citation near the claim, use a source or notes slide for longer references, or place source details in speaker notes when the tool supports them. Include enough information to identify the source, such as its organization or author, title, date, and link when available.

Keep source notes readable and consistent. Do not imply that a claim is independently verified if it came only from supplied material. If a source cannot be accessed or checked, say so and avoid presenting its contents as confirmed.

Research only what supports the stated purpose. If reliable source access is unavailable and unsupported facts would materially change the result, ask whether to use only supplied material or pause for sources.
When sources are requested, format in-text citations and the reference list in APA 7. For undated webpages designed to change over time, use the organization as author, “n.d.” as the date, a descriptive page title, and a retrieval date. Use letter suffixes (n.d.-a, n.d.-b) for multiple undated works by the same author, matching the in-text citations to the reference list. Cite real-world design examples by creator or organization, date when available, title or description, source/site, and direct URL; distinguish visual inspiration from evidence for factual claims.
