# Type System and Pairing Selection

Choose typography independently from style, palette, product category, and presentation structure. Start with audience, language, tone, viewing distance, output platform, and the amount of text on a typical slide. Prefer readable body shapes and a clear hierarchy over novelty.

## Define roles

Set roles for title/display, section heading, slide heading, body, caption/source note, and data label. Choose a consistent scale, weights, line spacing, and alignment. A single type family with multiple weights is often sufficient; a common pairing uses one heading face and one body face. Add another family only when it has a clear, distinct purpose.

## Pairing examples are candidates

The example pairings in this folder are independent candidates, not fixed companions to any style, palette, product category, or presentation structure. Verify font availability in the selected platform and supplied brand kit. If a face is unavailable, choose a verified substitute with similar proportions, weight, and character, and disclose the substitution.

## Review before use

Test actual headlines, body text, numerals, punctuation, chart labels, and language characters. Check glyph coverage, wrapping, clipping, contrast, and export output at presentation size. Keep captions and footnotes readable. Do not solve overflow by shrinking all text; revise the layout or copy when needed. These checks apply to every pairing example, so the individual pairing files focus on the combinations and their distinctive trade-offs.
