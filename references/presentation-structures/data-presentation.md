# Data Presentation

## Purpose

Help an audience interpret evidence and understand its implication.

## Flexible story pattern

Decision-relevant finding → supporting data → explanation and caveats → implication or action

## How to adapt it

Lead with the decision-relevant finding or question, then show only data needed to support it. Explain method, measure, population, period, and source. Separate observed results from interpretation; disclose uncertainty, limitations, missing data, and alternative explanations. Use charts that answer the question and avoid dense dashboards without a takeaway.
