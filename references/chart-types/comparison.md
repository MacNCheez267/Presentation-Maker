# Category Comparisons

Use these displays when the main question is how values differ across named groups. Decide whether viewers need exact comparisons, rank order, composition within each group, or a quick visual scan. Use the same units and consistent scales; do not make visual differences larger than the data supports.

| Chart type | Use when | Avoid or check |
|---|---|---|
| Bar or column | Comparing values across categories or showing a small number of series | Keep series limited; use a zero baseline for magnitude comparisons; label grouped segments clearly |
| Stacked bar or column | Comparing totals and component composition across a few categories | Keep series and segments limited; use consistent order and labels; totals must be meaningful |
| Dot plot | Comparing individual values or distributions with less visual weight than bars | Keep the scale and category order clear; avoid dense labels |
| Small multiples | Comparing the same measure across several groups or periods | Keep scales and encodings consistent across panels |

## Choose among comparison displays

- Use a sorted bar chart when rank and magnitude are the main message; use the natural or meaningful order when categories have an inherent sequence.
- Use grouped bars when viewers need to compare a few series within each category. Use small multiples when the groups or series make a shared chart crowded, keeping axes comparable unless a clearly labeled scale change is necessary.
- Use a dot plot when exact position is more useful than filled bar area, especially for a compact set of values. A table is often clearer when readers need exact values for many categories.
- Use a stacked bar only when both the total and the components matter and viewers can compare the segments reliably. Prefer grouped bars or a table when precise component comparisons are central.
