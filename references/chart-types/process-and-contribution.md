# Stages, Contributions, and Progress

Use these displays when the audience needs to follow a real sequence or understand how inputs contribute to a result. Keep stage definitions and denominators consistent. Choose a simple labeled diagram instead when the tool does not support the native chart or the process is conceptual rather than quantitative.

| Chart type | Use when | Avoid or check |
|---|---|---|
| Funnel | Showing values across a genuine sequence of stages | Keep stages ordered and denominators clear; do not use for non-sequential data |
| Waterfall | Showing how increments and decrements produce a net change | Clearly distinguish starting, intermediate, and ending totals |
| Infographic count or progress display | Showing a simple count or progress measure for a broad audience | State scale, units, and completeness; avoid decorative icons that distort quantities |

## Selection cues

- Use a funnel only when stages form a genuine ordered pathway and each value uses a consistent population or denominator. Show conversion or drop-off definitions; use a bar chart when categories are not stages.
- Use a waterfall when viewers need to see how positive and negative changes produce a final total. Label subtotal and total bars distinctly; use a simple before-and-after comparison when intermediate contributions are not important.
- Use a progress display for a single, well-defined measure with a visible scale and completion point. Do not use decorative icons as unit counts unless each icon represents the same quantity and the scale is explicit.
