# Distributions and Relationships

Use these displays to show spread, clustering, association, and unusual observations. Explain axes, bins, scales, and summary marks in audience-friendly language. A visible association does not establish cause, and small samples may make apparent patterns unstable.

| Chart type | Use when | Avoid or check |
|---|---|---|
| Scatter or bubble | Showing relationships, patterns, outliers, or point comparisons | Explain axes and bubble size; reduce overlap; do not imply causation from correlation |
| Histogram | Showing the distribution of numeric values across bins | Label bin ranges; do not use for ordinary category counts |
| Box plot | Summarizing spread, median, and outliers across groups | Explain unfamiliar components; do not hide small samples or distribution detail |
| Heat map | Showing magnitude across two categorical or ordered dimensions | Include a legible scale; use labels or patterns so color is not the only cue |

## Selection cues

- Use a histogram for one numeric variable when binning helps explain its shape. State bin boundaries or a useful interval; results can change with bin width, so do not imply that one choice is uniquely correct.
- Use a box plot to compare distributions compactly across groups when the audience understands—or can be shown—median, spread, and outliers. Use a dot or strip plot when sample sizes are small and individual observations matter.
- Use a scatter plot to examine the relationship between two numeric variables. Identify units and any transformations; use a trend line only when it is analytically justified. Association alone does not establish causation.
- Use a heat map for a two-dimensional pattern when a shared scale and legible labels make the comparison clear. If precise values matter more than pattern, use a table or sorted chart instead.
