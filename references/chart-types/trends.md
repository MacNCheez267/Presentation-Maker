# Trends and Change Over Time

Use ordered time displays when sequence and change are the point. Confirm the time interval, missing periods, and whether values are cumulative. Avoid connecting observations that have no meaningful order, and make uneven spacing visible when it changes interpretation.

| Chart type | Use when | Avoid or check |
|---|---|---|
| Line | Showing change over time or another meaningful order | Do not connect unrelated categories; make gaps and irregular intervals clear |
| Area | Showing cumulative change or a total over time | Overlapping areas can hide values; use only when the filled area has meaning |
| Timeline | Showing dated events or phases in sequence | Preserve proportional timing when relevant; do not imply precise scale when the layout is illustrative |

## Choose a time display

- Use a line chart for repeated observations across meaningful, generally ordered intervals. Label the interval and units, show gaps in the data, and avoid connecting periods whose spacing or order is not meaningful.
- Use an area chart when the filled region communicates a cumulative total or meaningful magnitude over time. For multiple series, check that overlap does not hide values; use lines or small multiples when comparisons become difficult.
- Use a timeline for dated events or phases when sequence matters more than precise measurement. Space events proportionally only when the time scale is intended to be interpreted quantitatively.
